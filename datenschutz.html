Rechtsrahmen und Zwecke

Die Bearbeitung von Personendaten richtet sich insbesondere nach dem Schweizer Datenschutzgesetz (DSG). Soweit die Datenschutz-Grundverordnung (DSGVO) auf eine Bearbeitung anwendbar ist, erfolgt die Bearbeitung zur sicheren und stabilen Bereitstellung der Website sowie zur Beantwortung von Anfragen auf Grundlage berechtigter Interessen gemäss Art. 6 Abs. 1 lit. f DSGVO. Bei vorvertraglichen Anfragen kann zusätzlich Art. 6 Abs. 1 lit. b DSGVO anwendbar sein.

Es finden keine automatisierten Einzelentscheidungen und kein Profiling statt.

Bereitstellung über GitHub Pages

Die Website wird derzeit über GitHub Pages bereitgestellt. Beim Aufruf werden technisch erforderliche Verbindungsdaten bearbeitet. GitHub nennt für Pages insbesondere die IP-Adresse der besuchenden Person, die zu Sicherheitszwecken protokolliert und gespeichert wird. Nach der allgemeinen Datenschutzerklärung von GitHub können zudem technische Verbindungs-, Geräte- und Nutzungsdaten anfallen.

Die Bearbeitung dient der Auslieferung der Website, der Systemsicherheit, der Missbrauchsabwehr und der Fehleranalyse. Empfänger dieser Daten ist GitHub beziehungsweise können von GitHub eingesetzte verbundene Unternehmen und Dienstleister sein. Der Betreiber dieser Website hat keinen Zugriff auf die von GitHub geführten Serverprotokolle und bestimmt deren Aufbewahrungsdauer nicht.

GitHub gibt an, Personendaten unter anderem in der jeweiligen Region, in den USA und in weiteren Ländern zu bearbeiten. Für internationale Übermittlungen nennt GitHub je nach Fall insbesondere das Data Privacy Framework und Standardvertragsklauseln. Massgeblich sind die jeweils aktuellen Angaben von GitHub.

Favoriten im Browser

Wenn eine Person ein Angebot mit dem Herz markiert, speichert der Browser ausschliesslich die interne Kennung dieses Angebots im lokalen Browserspeicher (localStorage). Die Daten werden nicht an den Betreiber übertragen, nicht geräteübergreifend synchronisiert und nicht zu Analyse- oder Werbezwecken verwendet.

Gespeicherter Schlüssel: weiterbildungsradar:favorites:v1. Einzelne Favoriten lassen sich durch erneutes Anklicken des Herzens entfernen. Alle Favoriten können durch Löschen der Website-Daten im Browser entfernt werden.

Kontakt per E-Mail

Wer per E-Mail Kontakt aufnimmt, übermittelt insbesondere E-Mail-Adresse, Namen, Inhalt, Anhänge sowie technische Nachrichtenmetadaten. Diese Angaben werden zur Bearbeitung und Beantwortung des Anliegens verwendet. Zugriff haben der Betreiber und die für den E-Mail-Betrieb eingesetzten Dienstleister.

Anfragen werden so lange aufbewahrt, wie dies für ihre Bearbeitung und für angemessene Anschlussfragen erforderlich ist. Geschäftlich oder rechtlich relevante Korrespondenz kann entsprechend gesetzlicher Pflichten länger aufbewahrt werden.

Hinweis vor der Lancierung: Der konkret eingesetzte E-Mail-Dienstleister und allfällige Auslandbearbeitungen müssen nach Einrichtung der Projektadressen an dieser Stelle ergänzt werden.

Keine Analyse- oder Werbetracker

Der eigene Website-Code verwendet keine Webanalyse, keine Werbetracker, keine Social-Media-Plugins und keine extern eingebetteten Schriften oder Videos. Er setzt selbst keine Cookies. Die unter «Favoriten im Browser» beschriebene lokale Speicherung wird erst durch die aktiv gewählte Favoritenfunktion ausgelöst.

Externe Angebotsseiten

Die Angebotskarten verlinken auf Websites unabhängiger Anbieter. Erst beim Anklicken eines Links wird die externe Website aufgerufen. Für deren Datenbearbeitungen und Datenschutzerklärungen ist der jeweilige Anbieter verantwortlich. Die Links werden mit technischen Schutzattributen geöffnet, die eine Übermittlung der Adresse der Ausgangsseite nach Möglichkeit unterbinden.

Rechte betroffener Personen

Betroffene Personen können im Rahmen des anwendbaren Rechts insbesondere Auskunft, Berichtigung, Löschung oder Einschränkung der Bearbeitung verlangen und einer Bearbeitung widersprechen. Soweit die DSGVO anwendbar ist, können zusätzlich ein Recht auf Datenübertragbarkeit und ein Beschwerderecht bei einer zuständigen Datenschutzaufsichtsbehörde bestehen.

Anfragen sind an datenschutz@weiterbildungsradar.ch zu richten. In der Schweiz kann zudem der Eidgenössische Datenschutz- und Öffentlichkeitsbeauftragte (EDÖB) kontaktiert werden.
